# Overlock installers

Installers for Overlock, self-storage facility management software by A Squared Software. This repository holds only the installers; the code is private.

Download the latest from [Releases](https://github.com/poulh/overlock-releases/releases/latest):

- **Windows:** `Overlock-Setup-<version>.exe`. Installed copies find new versions here and offer "Restart to install".
- **Mac:** `Overlock-<version>-arm64.dmg` (Apple Silicon) or `-x64.dmg` (Intel), when published. Mac copies don't update themselves yet.
